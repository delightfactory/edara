# خارطة طريق نظام الموارد البشرية المتكامل — EDARA
> **مرحلة مؤجلة — للتنفيذ بعد استكمال المراحل الأساسية**
> آخر تحديث: 2026-03-13

---

## 1. نظام الحضور والانصراف

- تسجيل الحضور عبر **GPS/Location** مع التحقق من الموقع
- تسجيل الانصراف مع حساب ساعات العمل تلقائياً
- دعم **ورديات متعددة** (صباحي، مسائي، مرن)
- تقارير تأخير وغياب يومية/شهرية
- ربط الحضور بالراتب والخصومات تلقائياً

### جداول DB المطلوبة
- `employee_attendance` — سجل الحضور + GPS coordinates
- `work_shifts` — تعريف الورديات
- `employee_shift_assignments` — ربط الموظف بالوردية

---

## 2. نظام الإجازات

- طلب إجازة مع اعتماد من المدير
- أنواع: سنوية، مرضية، بدون راتب، طوارئ
- رصيد إجازات سنوي تلقائي
- تأثير الإجازات على الراتب

### جداول DB المطلوبة
- `employee_leaves` — طلبات الإجازات + حالة الاعتماد
- `leave_balances` — أرصدة الإجازات السنوية

---

## 3. نظام الرواتب والحوافز

- حساب الراتب الشهري: أساسي + بدلات - خصومات = صافي
- ربط **الأهداف والأنشطة → الحوافز → الراتب**
- ربط **الحضور → الخصومات** (تأخير/غياب)
- ربط **المكافآت والجزاءات → الراتب**
- تقرير وتصدير كشف الرواتب الشهري

### جداول DB المطلوبة
- `payroll_runs` — كشف الرواتب الشهري
- `payroll_items` — بنود الراتب (بدلات، خصومات، حوافز)
- `employee_rewards_penalties` — مكافآت وجزاءات

---

## 4. صفحة الموظف الشاملة (Employee Profile Dashboard)

| القسم | المحتوى |
|-------|---------|
| البيانات الأساسية | الاسم، القسم، المسمى، تاريخ التعيين |
| الحساب المالي | الراتب الحالي، المكافآت، الخصومات |
| سجل الحضور | ملخص شهري + تفاصيل يومية |
| الإجازات | رصيد متبقي + سجل الإجازات |
| المكافآت والجزاءات | سجل كامل مع الأسباب |
| الأهداف والأداء | نسبة تحقيق الأهداف (للمندوبين) |
| العملاء المسندين | قائمة العملاء (للمندوبين) |

## 5. دعم كافة أنواع الموظفين

| الدور | القسم | الأنشطة المتتبعة |
|-------|-------|-------------------|
| مندوب مبيعات | المبيعات | زيارات، طلبات، تحصيل |
| سائق توصيل | اللوجستيات | توصيلات، مرتجعات |
| أمين مخزن | المخازن | استلام، صرف، جرد |
| محاسب | المالية | قيود، تسويات |
| مسوّق | التسويق | حملات، عملاء جدد |
| مشرف عمليات | العمليات | اعتمادات، متابعة |
| مدير قسم | الإدارة | اعتمادات، تقارير |

### متطلبات التتبع
- كل نوع موظف له **أنشطة محددة** يتم تتبعها
- ربط الأنشطة بـ **KPIs** قابلة للقياس
- ربط KPIs بـ **حوافز ومكافآت** تلقائية
